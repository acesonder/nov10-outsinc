# OUTSINC Feature Overview

## 🎯 Core Mission
OUTSINC (Outreach Someone In Need of Change) connects people experiencing homelessness, mental health issues, or substance use challenges with essential resources, compassionate support, and community assistance.

---

## 👥 User Roles & Access

### 🆘 Recipients (Those Seeking Help)
**Purpose**: Find resources and request assistance

**Key Features**:
- Browse service directory anonymously or with account
- Submit help requests (anonymous or identified)
- Track case status and updates
- Save favorite resources
- Attend community events
- Receive real-time notifications
- Share success stories
- Direct messaging with volunteers/staff

**Dashboard View**:
- Open help requests
- Saved resources
- Upcoming events
- Notification feed

### 📋 Case Management System

**For Recipients**:
- Submit help requests
- Choose anonymous or identified submission
- Track request status
- Add priority levels
- Receive updates via notifications

**For Staff/Volunteers**:
- View all cases or assigned cases
- Update case status (Open → In Progress → Closed)
- Add private or public notes
- Complete case history/timeline
- Filter by status, priority, type

**Case Statuses**:
- 🔵 Open - New request
- 🟡 In Progress - Being addressed
- 🟢 Closed - Successfully resolved
- 🔄 Follow-up - Requires additional attention

**Priority Levels**:
- 🔴 Urgent
- 🟠 High
- 🟡 Medium
- ⚪ Low

## 🚀 Technical Highlights

### Backend
- **Language**: PHP 7.4+
- **Database**: MySQL 5.7+
- **Architecture**: MVC-inspired
- **Security**: Prepared statements, input validation
- **Session Management**: Secure PHP sessions

### Frontend
- **HTML5**: Semantic markup
- **CSS3**: Modern styling, flexbox, grid
- **JavaScript**: ES6+, async/await
- **jQuery**: DOM manipulation, AJAX
- **Font Awesome**: 1000+ icons
- **DataTables**: Advanced table features

### Database Design
- 15+ normalized tables
- Foreign key constraints
- Indexed columns for performance
- JSON support for flexible data
- Audit trail logging

### File Structure
```
outsinc/
├── admin/          # Admin interface
├── api/            # REST-like endpoints
├── assets/         # Static assets
├── database/       # Schema & migrations
├── includes/       # Core PHP files
```
